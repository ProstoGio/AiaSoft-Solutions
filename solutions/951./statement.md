# Problem Statement — 951. რიგები

> Copied from [AiaSoft.ge #951](https://aiasoft.ge/problem/951)

**Time limit:** 1.0s &nbsp;|&nbsp; **Memory limit:** 256 MB

## Task

Aiasoft ატარებს პროგრამირების კონკურსს. რეგისტრაციის დასრულების შემდეგ აღმოჩნდა, რომ კონკურსში მონაწილეთა რაოდენობა არის N.
დარბაზში მონაწილეები რიგებად უნდა განთავსდნენ, ისე რომ თითოეულ რიგში მაქსიმუმ M მონაწილე ისხდეს.

დაადგინეთ, მინიმუმ რამდენი რიგია საჭირო ყველა მონაწილის განსათავსებლად.

## Input

ერთ სტრიქონში მოცემულია ორი მთელი რიცხვი 1 ≤ N,M ≤ 10¹⁸

## Output

გამოიტანეთ ერთი მთელი რიცხვი — რიგების მინიმალური რაოდენობა.
