# Problem Statement — 949. შოკოლადის ფილა

> Copied from [AiaSoft.ge #949](https://aiasoft.ge/problem/949)

**Time limit:** 1.0s &nbsp;|&nbsp; **Memory limit:** 256 MB

## Task

მარის და ტასოს შოკოლადის ფილა აქვთ, რომელიც N ცალი პატარა ნატეხისგან შედგება. ისინი თამაშობენ თამაშს შემდეგი წესებით:
	● თამაშს იწყებს მარი;
	● მოთამაშეს თავის სვლაზე შეუძლია შოკოლადის ფილიდან მოტეხოს და შეჭამოს 1, 2 ან 3 ცალი ნატეხი;
	● მოგებულია ის, ვინც გააკეთებს ბოლო სვლას, ანუ შეჭამს ბოლო ნატეხს და დაასრულებს თამაშს.
ჩათვალეთ, რომ ორივე მოთამაშე თამაშობს ოპტიმალურად (არ უშვებს შეცდომას) და დაადგინეთ მოგებული მოთამაშე.


`~https://storage.googleapis.com/problems_api_photos/images/FbZLc5l9lMEA13qLrtwO.png`

## Input

ერთადერთ ხაზზე მოცემულია რიცხვი N - შოკოლადში ფილის ნატეხების რაოდენობა.
1≤N≤10⁹

## Output

გამოიტანეთ გამარჯვებულის სახელი - “Mari” ან “Taso”.
დაბეჭდეთ “Unknown” თუ პასუხის დადგენა შეუძლებელია.
