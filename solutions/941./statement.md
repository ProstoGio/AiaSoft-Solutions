# Problem Statement — 941. წყლის სვეტები

> Copied from [AiaSoft.ge #941](https://aiasoft.ge/problem/941)

## Task

ლაბორატორიაში მოთავსებულია წყლის სპეციალური ჭურჭელი, რომელიც ერთმანეთისგან იზოლირებული N რაოდენობის ვერტიკალური სექციისგან შედგება. თითოეულ სექციაში საწყის მომენტში ჩასხმულია სხვადასხვა მოცულობის წყალი. მეზობელ სექციებს შორის, ძირში, დამონტაჟებულია სპეციალური ონკანები (სარქველები), რომლებიც საწყის მომენტში დაკეტილია `i(ნახაზი 1)`.

ერთ სვლაზე ჩვენ შეგვიძლია ავირჩიოთ ნებისმიერი ორი მეზობელი სექცია და გავხსნათ მათ შორის არსებული ონკანი. ონკანის გახსნისას, ამ ორ სექციაში წყლის დონეები თანაბრდება `i(ნახაზი 2)`. წყლის დონეების გათანაბრების შემდეგ ონკანი ისევ იხურება `i(ნახაზი 3)`.

ელენე ამ ოპერაციას ასრულებს რამდენჯერმე (ან არცერთჯერ), ნებისმიერი თანმიმდევრობით. მისი მიზანია, პროცესის დასრულების შემდეგ, რომელიმე ერთ სექციაში მაინც მიიღოს წყლის მაქსიმალური შესაძლო დონე. დაეხმარეთ ელენეს მიზნის მიღწევაში.

## Input

პირველ ხაზზე მოცემულია რიცხვი N - ჭურჭლის სექციების რაოდენობა.
მეორე ხაზზე მოცემულია N ცალი მთელი რიცხვი - თავდაპირველი წყლის დონეები სექციებში (მარცხნიდან მარჯვნივ)
2≤N≤10⁵
0≤hi≤10⁹

## Output

გამოიტანეთ ერთი რიცხვი - წყლის მაქსიმალური დონე, რომლის მიღებაც შესაძლებელია ოპერაციების ოპტიმალურად ჩატარების შედეგად.
