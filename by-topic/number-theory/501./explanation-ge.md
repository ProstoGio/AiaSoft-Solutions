# განმარტება — 501. რამდენიმე რიცხვის უსგ

## მიდგომა

ეს ამოცანა არის კლასიკური შემთხვევა, როცა რამდენიმე რიცხვის უსგ უნდა იპოვო. მთავარი იდეა ისაა, რომ უსგ არის ასოციაციური ოპერაცია, ანუ GCD(a, b, c) იგივეა, რაც GCD(GCD(a, b), c). ამიტომ, უბრალოდ ვინახავ პირველ რიცხვს ცვლადში და მერე ციკლით მივყვები დანარჩენებს, ყოველ ჯერზე ვანახლებ ცვლადს მიმდინარე რიცხვთან უსგ-ის გამოთვლით. C++-ის ჩაშენებული `gcd` ფუნქცია ძალიან მოსახერხებელია და პირდაპირ ამას აკეთებს.

## სირთულე

| | |
|-|--|
| დრო | O(N * log(min(A))) |
| მეხსიერება | O(N) |

## მთავარი დაკვირვებები

- უსგ-ის თვისება: GCD(a, b, c) = GCD(GCD(a, b), c)
- std::gcd ფუნქციის გამოყენება საუკეთესო პრაქტიკაა, არაა საჭირო ველოსიპედის გამოგონება.
- რიცხვების დალაგება (sort) ამ კონკრეტულ ამოცანაში სავალდებულო არაა, მაგრამ კოდს უფრო მოწესრიგებულს ხდის.

## ხშირი შეცდომები

- 0-ის შემთხვევის გამოტოვება, თუმცა GCD(a, 0) = a წესით მაინც სწორად იმუშავებს.
- ყველა გამყოფის პოვნის მცდელობა, რაც დროში გაწელავს ამოხსნას.
- int ტიპის გამოყენება, როცა რიცხვები 2*10^9-ია, თუმცა აქ 32-ბიტიანში მაინც ეტევა.

## ნაბიჯ-ნაბიჯ ახსნა

ჯერ რიცხვებს ვინახავ ვექტორში. შემდეგ `temp` ცვლადს ვატოლებ პირველ ელემენტს და ციკლით ვუვლი დანარჩენებს. ყოველ ნაბიჯზე `temp` ხდება თავისივე და მიმდინარე ელემენტის უსგ. როცა ციკლი დასრულდება, `temp`-ში ზუსტად ის რიცხვი იქნება, რაც გვინდა.
