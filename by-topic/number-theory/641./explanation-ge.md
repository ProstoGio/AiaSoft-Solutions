# განმარტება — 641. მიმდევრობის წევრი

## მიდგომა

ამოცანა დადის ბეზუს იდენტობაზე. რადგან a_1*b_1 + ... + a_n*b_n ფორმის გამოსახულება ყოველთვის იყოფა a_i-ების უდიდეს საერთო გამყოფზე (GCD), საკმარისია გავიგოთ მთელი მასივის GCD. თუ შემოტანილი x იყოფა ამ რიცხვზე, ესე იგი პასუხია YES.

## სირთულე

| | |
|-|--|
| დრო | O(N * log(min(A)) + Q) |
| მეხსიერება | O(N + Q) |

## მთავარი დაკვირვებები

- ნებისმიერი წრფივი კომბინაცია a_1, a_2, ..., a_n რიცხვების GCD-ს ჯერადია.
- ნულების შემთხვევაში განსაკუთრებული ყურადღება გვჭირდება.
- std::gcd ფუნქცია მუშაობს ძალიან სწრაფად და კოდს ამარტივებს.

## ხშირი შეცდომები

- აბსოლუტური მნიშვნელობის (abs) გამოტოვება GCD-ს გამოთვლისას.
- ნულის შემთხვევის არასწორად დამუშავება.

## ნაბიჯ-ნაბიჯ ახსნა

თავიდან ვინახავ მასივს, შემდეგ `std::gcd`-ს გამოყენებით ვპოულობ მთელი მასივის საერთო გამყოფს. როცა GCD ვიცი, თითოეულ Q-სთვის უბრალოდ ვამოწმებ x % g == 0-ს. თუ 0-ია, ვბეჭდავ YES-ს, თუ არა - NO-ს.
