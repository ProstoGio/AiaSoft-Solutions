# Problem Statement — 726. მრავალჯერადი ფაქტორიალი

> Copied from [AiaSoft.ge #726](https://aiasoft.ge/problem/726)

**Time limit:** 1.0s &nbsp;|&nbsp; **Memory limit:** 256 MB

## Task

როგორც ვიცით აღნიშვნა n! (n მთელი რიცხვია) აღნიშნავს n-ის ფაქტორიალს და გამოითვლება შემდეგნაირად: n! = 1 * 2 * 3 * ... * n. ასევე ცნობილია, რომ 0! = 1.

ახლა განვსაზღვროთ მრავალჯერადი ფაქტორიალი. მაგალითად, n-ის ორჯერადი ფაქტორიალი n!! გამოითვლება შემდეგნაირად: n!! = (n!)! = 1 * 2 * 3 * ... * n!, სამჯერადი ფაქტორიალი n!!! = ((n!)!)! = 1 * 2 * 3 * ... * n!! და ა. შ.

მოცემულია მრავალჯერადი ფაქტორიალის ჩანაწერი - გამოთვალეთ, რა ციფრით ბოლოვდება გამოთვლილი ფაქტორიალი.

## Input

ერთ ხაზზე მოცემულია სტრიქონი შემდეგი ფორმატით: n!!!... (სამი წერტილი ნიშნავს, რომ ფაქტორიალის ჯერადობა განსაზღვრული არაა).
გარანტირებულია, რომ n მთელი რიცხვია 0 <= n <= 100 და შემოსულ სტრიქონში '!' სიმბოლოების რაოდენობა მინიმუმ 1 და მაქსიმუმ 10 იქნება.

## Output

გამოიტანეთ ერთი ციფრი: გამოთვლილი ფაქტორიალის ბოლო ციფრი.
