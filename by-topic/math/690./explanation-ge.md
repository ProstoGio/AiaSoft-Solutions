# განმარტება — 690. საშუალო პროგრამისტული

## მიდგომა

ამოცანა საკმაოდ მარტივია, პირდაპირ უნდა მიჰყვე პირობაში მოცემულ ფორმულას. ვკითხულობთ ორ რიცხვს, ვამრავლებთ ერთმანეთზე და ვაკლებთ მათ ჯამს. თუ მიღებული რიცხვი ნულზე მეტი ან ტოლია, მაშინ ვბეჭდავთ 'high', სხვა შემთხვევაში 'low'. მიუხედავად იმისა, რომ რიცხვები პატარაა, `long long`-ის გამოყენება ჩვევად მაქვს, რომ ზედმეტი თავის ტკივილი ავირიდო.

## სირთულე

| | |
|-|--|
| დრო | O(1) |
| მეხსიერება | O(1) |

## მთავარი დაკვირვებები

- ფორმულაა: (a * b) - (a + b).
- არ დაგავიწყდეს, რომ ნული 'high' კატეგორიაში გადის, რადგან პირობა ამბობს 'არაუარყოფითიაო'.

## ხშირი შეცდომები

- პირობის არასწორად წაკითხვა და ნულის 'low'-ში გატანა.
- მინუსიანი რიცხვების გამოკლებისას ნიშნების არევა.

## ნაბიჯ-ნაბიჯ ახსნა

კოდი უბრალოდ იღებს ორ მთელ რიცხვს, ითვლის გამოსახულებას და `if-else`-ით ამოწმებს პირობას. მეტი არაფერი სჭირდება.
