# Problem Statement — 690. საშუალო პროგრამისტული

> Copied from [AiaSoft.ge #690](https://aiasoft.ge/problem/690)

**Time limit:** 1.0s &nbsp;|&nbsp; **Memory limit:** 256 MB

## Task

ჩვენთვის ცნობილ მათემატიკურ ტერმინებს ერთი ახალი ტერმინი შეემატა - საშუალო პროგრამისტული. ეს ტერმინი აღნიშნავს ორი ან მეტი რიცხვის ნამრავლს გამოკლებული მათი ჯამი. საშუალო პროგრამისტულს ეწოდება მაღალი რიგის თუ ის არაუარყოფითია, წინააღმდეგ შემთხვევაში მასე წოდება დაბალი რიგის.

## Input

პირველ სტრიქონზე შემოდის ორი მთელი რიცხვი a და b (-10⁴<=a,b<=10⁴)

## Output

პირველ სტრიქონზე დაბეჭდეთ სიტყვა "high", თუ მოცემული რიცხვების საშუალო პროგრამისტული მაღალი რიგისაა, წინააღმდეგ შემთხვევაში დაბეჭდეთ სიტყვა "low".
