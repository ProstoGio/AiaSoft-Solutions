# Problem Statement — 853. გამოკლება ლაშას წესით

> Copied from [AiaSoft.ge #853](https://aiasoft.ge/problem/853)

**Time limit:** 1.0s &nbsp;|&nbsp; **Memory limit:** 256 MB

## Task

ლაშამ გამოკლება ისწავლა. იგი ჯერ პატარაა და არ იცის უარყოფითი რიცხვების არსებობის შესახებ. ერთ დღეს დედამ მეცადინეობისას ლაშას სავარჯიშოდ რამდენიმე მაგალითი დაუწერა და სთხოვა გამოეთვალა სხვაობები. თუმცა უნებურად ზოგი ისეთი მაგალითიც გამოურია, სადაც საკლები მაკლებზე ნაკლებია. ასეთმა შემთხვევებმა კი ლაშა დააბნია და მან თავისი მეთოდი შეიმუშავა: თუ გამოკლებისას საკლები მაკლებზე ნაკლებია, მაშინ პასუხი ნულია - თქვა მან და ამ პრინციპით განაგრძო მაგალითების ამოხსნა.
მოცემულია დედას მიერ ფურცელზე ჩამოწერილი მაგალითები. თითოეული მათგანისთვის დაადგინეთ - რა პასუხს მიიღებდა ლაშა.

## Input

მოცემულია გაურკვეველი რაოდენობის მაგალითი ცალ-ცალკე ხაზზე შემდეგი პრინციპით: x-y, სადაც 0 <= x, y <= 100
გარანტირებულია, რომ მაგალითების რაოდენობა არ აღემატება 100-ს.

## Output

თითოეული შემოსული მაგალითისთვის გამოთვალეთ პასუხი ლაშას წესის მიხედვით და გამობეჭდეთ პასუხი ცალკე ხაზზე.
