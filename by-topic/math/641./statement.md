# Problem Statement — 641. მიმდევრობის წევრი

> Copied from [AiaSoft.ge #641](https://aiasoft.ge/problem/641)

**Time limit:** 1.0s &nbsp;|&nbsp; **Memory limit:** 256 MB

## Task

თაკოს აქვს N რიცხვისგან შედგენილი მიმდევრობა: a1, a2, ..., an და ამ რიცხვებისგან ახალ, უსასრულო მიმდევრობას ქმნის, რომლის წევრებსაც შემდეგი წესით აგენერირებს:

● შევარჩიოთ რაიმე N მთელი რიცხვისგან შედგენილი მიმდევრობა: b1, b2, ..., bn
● გამოვთვალოთ შემდეგი გამოსახულების მნიშვნელობა: a1b1 + a2b2 + ... + anbn
● ბოლოს კი მიღებული შედეგი ჩავამატოთ ახალ მიმდევრობაში

თაკოს აინტერესებს, აღმოჩნდება თუ არა x ახალ, უსასრულო მიმდევრობაში.

## Input

პირველ ხაზზე მოცემულია ორი მთელი რიცხვი: N და Q
მეორე ხაზზე შემოდის N რაოდენობის მთელი რიცხვი: a1, a2, ..., aN
მესამე ხაზზე მოცემულია Q რაოდენობის მთელი რიცხვი: x1, x2, ..., xQ

1 <= N <= 10⁵
1 <= Q <= 10³
0 <= |ai|, |xi| <= 10¹²

## Output

ყოველი xi-სთვის ცალ-ცალკე ხაზზე გამობეჭდეთ ერთი სიტყვა: `bYES` - თუ xi აღმოჩნდება თაკოს მიერ მიღებულ მიმდევრობაში, წინააღმდეგ შემთხვევაში - `bNO`
