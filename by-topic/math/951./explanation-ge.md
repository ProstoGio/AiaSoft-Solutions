# განმარტება — 951. რიგები

## მიდგომა

ეს არის მარტივი გაყოფის ამოცანა. უნდა გავიგოთ, რამდენი რიგი დაგვჭირდება N ადამიანის M-M-ად განაწილებისთვის. თუ N იყოფა M-ზე უნაშთოდ, პასუხი უბრალოდ N/M-ია. თუ ნაშთი გვაქვს, ესე იგი დამატებითი რიგია საჭირო დარჩენილი ხალხისთვის, ამიტომ ვუმატებთ ერთს.

## სირთულე

| | |
|-|--|
| დრო | O(1) |
| მეხსიერება | O(1) |

## მთავარი დაკვირვებები

- N/M-ის 'ჭერის' (ceiling) პოვნა გვინდა.
- აუცილებლად უნდა გამოვიყენოთ long long, რადგან მონაცემები 10^18-მდეა.

## ხშირი შეცდომები

- int ტიპის გამოყენება, რაც 10^18-ის დროს აუცილებლად overflow-ს მოგცემს.
- ციკლის გამოყენება რიგების სათვლელად, რაც ძალიან ნელი იქნება.

## ნაბიჯ-ნაბიჯ ახსნა

შემოგვაქვს n და m, ვამოწმებთ n % m-ს. თუ 0-ია, ვბეჭდავთ განაყოფს. სხვა შემთხვევაში, ვბეჭდავთ განაყოფს პლუს ერთი.
