# განმარტება — 053. მართკუთხედი

## მიდგომა

მართკუთხედის პერიმეტრის ფორმულა არის P = 2 * (a + b). აქედან ჩანს, რომ პერიმეტრი აუცილებლად ლუწი უნდა იყოს, რადგან ნებისმიერ რიცხვს ორზე რომ გავამრავლებთ, ლუწი გამოდის. ასევე, რადგან გვერდები მთელი რიცხვებია, ყველაზე პატარა მართკუთხედი არის 1x1 კვადრატი, რომლის პერიმეტრიც 4-ია. შესაბამისად, თუ P კენტია ან 4-ზე ნაკლებია, პასუხი ავტომატურად 0 იქნება.

## სირთულე

| | |
|-|--|
| დრო | O(1) |
| მეხსიერება | O(1) |

## მთავარი დაკვირვებები

- პერიმეტრი ყოველთვის ლუწი რიცხვი უნდა იყოს
- P უნდა იყოს მინიმუმ 4

## ხშირი შეცდომები

- კენტი რიცხვების გაუთვალისწინებლობა
- ზღვრული მნიშვნელობების (4-ზე ნაკლები) გამოტოვება

## ნაბიჯ-ნაბიჯ ახსნა

კოდი მარტივია: შემოგვაქვს P და ვამოწმებთ პირობას. თუ P < 4 ან P-ს 2-ზე გაყოფისას ნაშთი არ არის 0, ვბეჭდავთ 0-ს. სხვა შემთხვევაში 1-ს.
