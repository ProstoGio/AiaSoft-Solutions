# განმარტება — 533. უახლოესი ჯერადი

## მიდგომა

ამ ამოცანის არსი იმაშია, რომ ვიპოვოთ b-ს უახლოესი ჯერადი რიცხვი a-სთვის. თუ a უკვე იყოფა b-ზე, პასუხი 0-ია. სხვა შემთხვევაში, პასუხი იქნება ან a-ზე ნაკლები უახლოესი ჯერადი, ან a-ზე მეტი. ქვედა ჯერადს მარტივად ვიგებ მთელი რიცხვითი გაყოფით (a/b)*b, ხოლო ზედას - ამ შედეგზე b-ს დამატებით. საბოლოოდ, ვადარებ მათ შორის მანძილს და გამოვიტან მინიმალურს.

## სირთულე

| | |
|-|--|
| დრო | O(n) |
| მეხსიერება | O(1) |

## მთავარი დაკვირვებები

- უახლოესი ჯერადი ყოველთვის არის ან (a/b)*b ან ((a/b)+1)*b.
- long long-ის გამოყენება სავალდებულოა, რადგან შეყვანის მონაცემები 10^16-ს აღწევს.

## ხშირი შეცდომები

- იმ შემთხვევის გამოტოვება, როცა a უკვე იყოფა b-ზე.
- int-ის გამოყენება, რამაც შეიძლება overflow გამოიწვიოს.

## ნაბიჯ-ნაბიჯ ახსნა

ვკითხულობთ n-ს და ვატრიალებთ ციკლს. თითოეული წყვილისთვის ვითვლით c1-ს, როგორც (a/b)*b, რაც არის a-ზე ნაკლები ან ტოლი ყველაზე დიდი ჯერადი. შემდეგი ჯერადი c2 არის c1+b. ბოლოს, პრინტავთ min(|a-c1|, |a-c2|) მნიშვნელობას.
