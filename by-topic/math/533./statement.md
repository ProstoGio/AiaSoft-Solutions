# Problem Statement — 533. უახლოესი ჯერადი

> Copied from [AiaSoft.ge #533](https://aiasoft.ge/problem/533)

**Time limit:** 1.0s &nbsp;|&nbsp; **Memory limit:** 256 MB

## Task

მოცემულია ორი ნატურალური რიცხვი a და b.  a რიცხვზე დასაშვებია ორი სახის არითმეტიკული ოპერაციის წარმოება:

	● ერთის დამატება;
	● ერთის გამოკლება.

დაადგინეთ, მინიმუმ რამდენი ოპერაცია დაგვჭირდება, რომ a რიცხვი გახდეს b-ს ჯერადი.

## Input

პირველ სტრიქონზე შემოდის ერთი ნატურალური რიცხვი n, 1<=n<=10⁵, სატესტო წყვილების რაოდენობა. 
მომდევნო n რაოდენობის სტრიქონიდან თითოეულზე შემოდის ორი ნატურალური რიცხვი: a და b. (1 <= a, b <= 10¹⁶)

## Output

გამოიტანეთ n რაოდენობის სტრიქონი, თითოეულ სტრიქონზე ჩაწერილი უნდა იყოს შესაბამისი ტესტის პასუხი.
