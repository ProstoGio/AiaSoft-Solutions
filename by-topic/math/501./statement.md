# Problem Statement — 501. რამდენიმე რიცხვის უსგ

> Copied from [AiaSoft.ge #501](https://aiasoft.ge/problem/501)

**Time limit:** 1.0s &nbsp;|&nbsp; **Memory limit:** 256 MB

## Task

მოცემულია N მთელი რიცხვისგან შედგენილი მიმდევრობა. გამოთვალეთ ამ რიცხვების უდიდესი საერთო გამყოფი.

## Input

პირველ ხაზზე მოცემულია ერთი მთელი რიცხვი: N (2 <= N <= 100)
მეორე ხაზზე მოცემულია N ცალი მთელი რიცხვი: a1, a2, ..., an (0 <= ai <= 2 * 10⁹)

## Output

გამობეჭდეთ ერთი მთელი რიცხვი: მოცემული რიცხვების უსგ.
