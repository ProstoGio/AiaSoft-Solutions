# Problem Statement — 488. გაყოფადობა 11-ზე

> Copied from [AiaSoft.ge #488](https://aiasoft.ge/problem/488)

**Time limit:** 1.0s &nbsp;|&nbsp; **Memory limit:** 256 MB

## Task

რიცხვი იყოფა 11-ზე თუ ამ რიცხვში კენტ ადგილზე მდგომი ციფრების ჯამს გამოკლებული ლუწ ადგილზე მდგომი ციფრების ჯამი იყოფა 11-ზე.

მოცემული N რიცხვისთვის დაადგინეთ იყოფა თუ არა ის 11-ზე.

## Input

შემოდის ერთი მთელი რიცხვი: N (1<=N<=10¹⁰⁰⁰)

## Output

ერთ ხაზზე გამობეჭდეთ `bYES` თუ რიცხვი იყოფა 11-ზე, წინააღმდეგ შემთხვევაში გამობეჭდეთ `bNO`.
