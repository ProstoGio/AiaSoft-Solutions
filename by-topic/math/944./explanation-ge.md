# განმარტება — 944. გაეროს შიფრი

## მიდგომა

ამოცანა საკმაოდ მარტივია, თუ მიხვდები, რომ შიფრაცია უკუღმა უნდა დააბრუნო. რადგან ყოველი ასო 'k * i'-თი გადაინაცვლებს მარჯვნივ, ჩვენ უბრალოდ უნდა გამოვაკლოთ ეს მნიშვნელობა და 'modulo 26'-ით დავუბრუნდეთ საწყის პოზიციას. 'k'-ს ბოლო სიმბოლოდან ვიღებ, შემდეგ კი ციკლში თითოეულ ასოს ვანაცვლებ უკან. მთავარი აქ ისაა, რომ (s[i] - 'A' - shift + 26) % 26 ფორმულა გამოვიყენო, რათა უარყოფითი რიცხვები არ მივიღო.

## სირთულე

| | |
|-|--|
| დრო | O(N) |
| მეხსიერება | O(N) |

## მთავარი დაკვირვებები

- შიფრი დინამიურია, ამიტომ თითოეული ასოსთვის shift-ი ინდექსის მიხედვით განსხვავდება.
- modulo-ს გამოყენებისას +26-ის მიმატება აუცილებელია უარყოფითი ნაშთის თავიდან ასაცილებლად.

## ხშირი შეცდომები

- ინდექსაციის არევა: ამოცანაში i-ს ათვლა 1-დან იწყება, მე კი 0-დან ვუყურებდი და მიწევდა (i+1)-ის გამოყენება.
- ბოლო ციფრის არასწორად ამოღება.

## ნაბიჯ-ნაბიჯ ახსნა

კოდი ჯერ კითხულობს სტრინგს, ბოლო სიმბოლოს 'k'-ად აქცევს, შემდეგ კი loop-ით გადის ყველა ასოზე. ყოველ ნაბიჯზე ვთვლი 'shift'-ს, ვაკლებ მას ასოს პოზიციას, ვაკეთებ modulo-ს და ვამატებ მიღებულ ასოს 'answer' სტრინგში.
