# Problem Statement — 125. ბაქტერია

> Copied from [AiaSoft.ge #125](https://aiasoft.ge/problem/125)

**Time limit:** 1.0s &nbsp;|&nbsp; **Memory limit:** 64 MB

## Task

მართკუთხედის ფორმის სხეულში, რომლის სიგრძე და სიგანე შესაბამისად არის N და M, ერთი უჯრედი დაავადდა ბაქტერიით. ბაქტერია ყოველ დღე ვრცელდება როგორც ვერტიკალურად და ჰორიზონტალურად, ასევე დიაგონალზეც. ანუ თუ დღეს დაავადდა რომელიმე უჯრედი, ხვალ მისი ყველა ვერტიკალური, ჰორიზონტალური და დიაგონალური მეზობელი უჯრედი დაავადდება.

დაადგინეთ, რამდენ დღეში დაავადდება სხეულის უჯრედი ინდექსით (x2, y2), თუ ბაქტერია გავრცელებას იწყებს (x1, y1) უჯრედიდან.

## Input

ერთ ხაზზე შემოდის 6 მთელი რიცხვი: N, M, x1, y1, x2, y2

1 <= x1, x2 <= N <= 10⁶
1 <= y1, y2 <= M <= 10⁶

## Output

გამოიტანეთ ერთი მთელი რიცხვი: რამდენ დღეში დაავადდება (x2, y2) უჯრედი.
