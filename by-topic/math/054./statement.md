# Problem Statement — 054. მონეტები

> Copied from [AiaSoft.ge #54](https://aiasoft.ge/problem/54)

**Time limit:** 1.0s &nbsp;|&nbsp; **Memory limit:** 128 MB

## Task

მოცემული გვაქვს ულიმიტო რაოდენობით 1, 2, ..., n თეთრიანი მონეტები. თქვენი სურვილია ამ მონეტებისგან შეარჩიოთ ისეთი კომპლექტი, რომ არჩეულმა მონეტებმა ჯამურად S თეთრი შეადგინოს. ნებადართულია კომპლექტში ერთნაირი მონეტების არსებობა. გამოთვალეთ მონეტების მინიმალური რაოდენობა, რითაც შეძლებთ S თეთრის მიღებას.

## Input

ერთ ხაზზე შემოდის ორი რიცხვი: n და S

1 ≤ n ≤ 10⁵
1 ≤ S ≤ 10⁹

## Output

გამოიტანეთ ერთი რიცხვი - ჯამურად S თეთრის მისაღებად საჭირო მონეტების მინიმალური რაოდენობა
