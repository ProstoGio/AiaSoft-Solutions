# Problem Statement — 908. სუნთქვა 2

> Copied from [AiaSoft.ge #908](https://aiasoft.ge/problem/908)

**Time limit:** 1.0s &nbsp;|&nbsp; **Memory limit:** 256 MB

## Task

ზუკა შეუწყვეტლად ითვლის 1-დან N-მდე. თან აკეთებს სუნთქვის პროცედურას შემდეგნაირად: თვლაზე "1-2" ჩაისუნთავს, ხოლო თვლაზე "3-4" ამოისუნთქავს, შემდეგ "5-6"-ზე ჩაისუნთქავს, "7-8"-ზე ისევ ამოისუნთავს და ა. შ.

დაადგინეთ, მე - N დათვლაზე რა ეტაპზეა ზუკა, ჩასუნთქვაზე თუ ამოსუნთქვაზე.

## Input

მოცემულია ერთი ნატურალური რიცხვი: N, (1 <= N <= 100)
ზუკა ითვლის 1-დან N-ის ჩათვლით.

## Output

გამობეჭდეთ "Breathe in", თუ ზუკა ჩასუნთქვის პროცესშია, წინააღმდეგ შემთხვევაში გამობეჭდეთ "Breathe out" .
