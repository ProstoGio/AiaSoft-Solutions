# განმარტება — 584. ვაშლები (მარტივი)

## მიდგომა

ამოცანის არსი იმაშია, რომ ვიპოვოთ N-ის ისეთი გამყოფი, რომ თითოეულ მოსწავლეს შეხვდეს 1-ზე მეტი ვაშლი. ეს იმას ნიშნავს, რომ თუ K არის მოსწავლეების რაოდენობა, მაშინ N/K უნდა იყოს 2-ზე მეტი ან ტოლი. მე უბრალოდ ვამოწმებ მცირე მარტივ რიცხვებზე გაყოფას, რათა ვიპოვო ყველაზე დიდი K, რომელიც დააკმაყოფილებს პირობას.

## სირთულე

| | |
|-|--|
| დრო | O(1) |
| მეხსიერება | O(1) |

## მთავარი დაკვირვებები

- პირობა '1-ზე მეტი ვაშლი' ნიშნავს, რომ მოსწავლეთა რაოდენობა უნდა იყოს N-ის გამყოფი, რომელიც მაქსიმუმ N/2-ის ტოლია.
- N=1 შემთხვევა ცალკე უნდა დამუშავდეს, რადგან ვაშლები არ რჩება.

## ხშირი შეცდომები

- N=1-ის არასწორად დამუშავება.
- იმის დავიწყება, რომ ვაშლები თანაბრად უნდა გადანაწილდეს.

## ნაბიჯ-ნაბიჯ ახსნა

თავიდან ვამოწმებ თუ N არის 1, მაშინ პასუხი 0-ია. შემდეგ რიგრიგობით ვამოწმებ გაყოფას 2-ზე, 3-ზე, 5-ზე და 7-ზე. რადგან N მაქსიმუმ 100-ია, ეს მიდგომა საკმარისია. თუ არცერთზე იყოფა, ესე იგი 1 მოსწავლეზე უნდა გავანაწილოთ ყველაფერი.
