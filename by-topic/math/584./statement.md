# Problem Statement — 584. ვაშლები (მარტივი)

> Copied from [AiaSoft.ge #584](https://aiasoft.ge/problem/584)

**Time limit:** 1.0s &nbsp;|&nbsp; **Memory limit:** 256 MB

## Task

ნიკას N რაოდენობის ვაშლი აქვს. მას სურს რომ ვაშლები თანაკლასელებს თანაბრად გაუნაწილოს ისე, რომ თითოეულ მათგანს 1-ზე მეტი ვაშლი შეხვდეს. მაქსიმუმ რამდენ თანაკლასელს შეუძლია გაუნაწილოს ნიკამ ვაშლი თუ ცნობილია, რომ ნიკას თავისთვის ვაშლი არ უნდა, ესე იგი მას ვაშლი არ უნდა დარჩეს (ნიკას N კლასელი ჰყავს).

## Input

მოცემულია ერთი ნატურალური რიცხვი: N - ვაშლების და ნიკას თანაკლასელების რაოდენობა. (1<=N<=100)

## Output

გამობეჭდეთ ერთი მთელი რიცხვი: იმ მეგობართა მაქსიმალური რაოდენობა, რომლებსაც ნიკა ვაშლს თანაბრად გაუნაწილებს.
