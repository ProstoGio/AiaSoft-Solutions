# Problem Statement — 748. ბედნიერი რიცხვები

> Copied from [AiaSoft.ge #748](https://aiasoft.ge/problem/748)

**Time limit:** 3.0s &nbsp;|&nbsp; **Memory limit:** 256 MB

## Task

მოცმეულია A და B რიცხვი, თქვენი დავალებაა A-დან B-მდე დათვალოთ ბედნიერი რიცხვების რაოდენობა. რიცხვს ეწოდება ბედნიერი თუკი ის 6-ნიშნა რიცხვია და  მისი პირველი სამი ციფრის ჯამი უდრის ბოლო სამი ციფრის ჯამს.

## Input

ერთადერთ ხაზზე მოცემულია ორი დადებითი მთელი რიცხვი A და B.
10⁵<=A<=B<10⁶

## Output

ერთადერთ ხაზზე გამობეჭდეთ რამდენი ბედნიერი რიცხვია A-B ინტერვალში.
