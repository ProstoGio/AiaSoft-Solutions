# განმარტება — 228. წაშლილი მატრიცა

## მიდგომა

რადგან მატრიცა n x n-ზეა, სტრიქონის სიგრძე ყოველთვის n-ის კვადრატი იქნება. ამიტომ, ზომის გასაგებად უბრალოდ ვიღებ სტრიქონის სიგრძის sqrt-ს. მთავარი დიაგონალის ელემენტები სტრიქონში განლაგებულია n+1 ნაბიჯით: 0, n+1, 2(n+1) და ასე შემდეგ. ამ ნაბიჯებით გავდივარ სტრიქონს, ვაკონვერტირებ ციფრებად და ვუმატებ ჯამს.

## სირთულე

| | |
|-|--|
| დრო | O(N) |
| მეხსიერება | O(N) |

## მთავარი დაკვირვებები

- ინდექსების დათვლა n+1-ით.
- char-დან int-ში გადაყვანა '0'-ის გამოკლებით.

## ხშირი შეცდომები

- char-ის პირდაპირ მიმატება ASCII მნიშვნელობით (მაგალითად '1' არის 49 და არა 1).
- სიგრძის არასწორი გამოთვლა.

## ნაბიჯ-ნაბიჯ ახსნა

ჯერ სტრიქონს ვკითხულობ. მერე ვითვლი n-ს, როგორც sqrt(s.size()). ვაკეთებ ციკლს, სადაც i იწყება 0-დან და იზრდება n+1-ით. ყოველ ჯერზე `s[i] - '0'`-ით ვიღებ რეალურ ციფრს და ვამატებ პასუხს.
