# განმარტება — 949. შოკოლადის ფილა

## მიდგომა

ეს კლასიკური თამაშის თეორიის ამოცანაა, სადაც ნაშთებთან გვაქვს საქმე. რადგან შეგვიძლია 1, 2 ან 3 ნატეხის აღება, ყოველი სრული 'რაუნდი' (მარი + ტასო) ჯამში 4-ს აკლებს ფილას. თუ N იყოფა 4-ზე, ტასო ყოველთვის მოიგებს, რადგან მარის სვლებს ისე 'ააბალანსებს', რომ ჯამი 4 იყოს. თუ N არ იყოფა 4-ზე, მარი პირველივე სვლით გადაიყვანს N-ს 4-ის ჯერადზე და მოიგებს.

## სირთულე

| | |
|-|--|
| დრო | O(1) |
| მეხსიერება | O(1) |

## მთავარი დაკვირვებები

- თუ N % 4 == 0, მაშინ მეორე მოთამაშე (Taso) იგებს.
- თუ N % 4 != 0, მაშინ პირველი მოთამაშე (Mari) იგებს.

## ხშირი შეცდომები

- N-ის დიდი მნიშვნელობის გამო (10^9) DP-ს გამოყენება, რაც ზედმეტია.
- ინტეგერების ტიპების არევა, თუმცა აქ int საკმარისია 10^9-ისთვის.

## ნაბიჯ-ნაბიჯ ახსნა

კოდი მარტივად კითხულობს N-ს და ამოწმებს n % 4 == 0 პირობას. თუ პირობა ჭეშმარიტია, ვბეჭდავთ 'Taso', სხვა შემთხვევაში კი 'Mari'.
