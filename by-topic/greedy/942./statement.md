# Problem Statement — 942. რა დარჩება?

> Copied from [AiaSoft.ge #942](https://aiasoft.ge/problem/942)

**Time limit:** 1.0s &nbsp;|&nbsp; **Memory limit:** 256 MB

## Task

მოცემულია N ელემენტიანი მასივი, რომლის ყველა ელემენტი მთელი დადებითი რიცხვია. ერთ სვლაზე შესაძლებელია მასივის ნებისმიერი ორი ელემენტის ამოკლება და მათი სხვაობის მოდულის* ჩამატება. თქვენი მიზანია დაადგინოთ ამ ოპერაციის N-1-ჯერ ჩატარების შემდეგ (რის შემდეგაც მასივში მხოლოდ 1 ელემენტი დარჩება) დარჩენილი რიცხვი ლუწი იქნება თუ კენტი.

*a რიცხვის მოდული არის a თუ a≥0 და არის -a თუ a<0

## Input

პირველ ხაზზე მოცემულია რიცხვი N - მასივში ელემენტების რაოდენობა.
მეორე ხაზზე მოცემულია N ცალი ელემენტი.
2≤N≤10⁵
0≤ai≤10⁹

## Output

დაბეჭდეთ “Even” თუ დარჩება ლუწი რიცხვი;
“Odd” თუ დარჩება კენტი რიცხვი;
“Unknown” თუ შესაძლებელია ან ლუწი მივიღოთ ან კენტი.
