# Problem Statement — 946. ოთო და ციფრები

> Copied from [AiaSoft.ge #946](https://aiasoft.ge/problem/946)

**Time limit:** 1.0s &nbsp;|&nbsp; **Memory limit:** 256 MB

## Task

ოთოს აქვს N სიგრძის ბინარული(რომელიც მხოლოდ 0 და 1 ციფრებისგან შედგება) სტრინგი S.

ერთ სვლაზე ოთოს შეუძლია აირჩიოს სტრინგის ნებისმიერი i-ური პოზიცია (2 ≤ i ≤ N-1), რომელიც ორ 1-იანს შორისაა (ანუ აუცილებლად სრულდება პირობა: Si-1 = 1 და Si+1 = 1), და არჩეული i-ური სიმბოლო შეცვალოს სურვილისამებრ - გახადოს ან 0 ან 1.

ოთოს შეუძლია ეს ოპერაცია შეასრულოს ნებისმიერი რაოდენობით (მათ შორის არცერთხელ). მისი მიზანია დაადგინოს, რა არის 1-იანების მინიმალური და მაქსიმალური შესაძლო რაოდენობა, რომელიც შეიძლება დარჩეს სტრიქონში ოპერაციების შესრულების შემდეგ.

## Input

სტანდარტული შეტანის პირველ ხაზზე მოცემულია ტესტების რაოდენობა T (1 ≤ T ≤ 500). 
შემდეგ მოცემულია თავად ტესტების აღწერა. თითოეული ტესტის პირველ ხაზზე მოცემულია ერთი მთელი რიცხვი N (3 ≤ N ≤ 100) - სტრიქონის სიგრძე. მეორე ხაზზე მოცემულია N სიგრძის ბინარული სტრიქონი S.

## Output

თითოეული ტესტისთვის გამოიტანეთ ორი მთელი რიცხვი - 1-იანების მინიმალური და მაქსიმალური შესაძლო რაოდენობა.
