# განმარტება — 702. ჰანოის კოშკი

## მიდგომა

ჰანოის კოშკი კლასიკური რეკურსიული ამოცანაა, სადაც მთავარია დავინახოთ კანონზომიერება: N დისკის გადასატანად ჯერ ზედა N-1 დისკი უნდა გადავიტანოთ დამხმარე ბოძზე, მერე ყველაზე დიდი დისკი მიზანში, და ბოლოს ის N-1 დისკიც მივაყოლოთ. ჩემს ფუნქციაში სამი ბოძი მაქვს: საწყისი, დამხმარე და სამიზნე. ყოველი ნაბიჯისას ამ ბოძების როლები იცვლება, რაც საშუალებას გვაძლევს ავტომატურად ავაწყოთ სწორი მიმდევრობა.

## სირთულე

| | |
|-|--|
| დრო | O(2^N) |
| მეხსიერება | O(N) |

## მთავარი დაკვირვებები

- მთლიანი სვლების რაოდენობა არის 2^N - 1, რაც პირდაპირ გამომდინარეობს რეკურსიული ფორმულიდან.
- მნიშვნელოვანია, რომ დამხმარე ბოძი ყოველთვის ისაა, სადაც დისკებს დროებით ვინახავთ.

## ხშირი შეცდომები

- რეკურსიულ გამოძახებებში ბოძების არასწორი თანმიმდევრობით გადაცემა.
- ბაზისური შემთხვევის (n=1) გამოტოვება ან არასწორად დამუშავება.

## ნაბიჯ-ნაბიჯ ახსნა

თავიდან ვიძახებთ hanoi(n, 1, 2, 3). თუ დისკი მხოლოდ ერთია, უბრალოდ ვბეჭდავთ მის გადატანას პირველიდან მესამეში. თუ მეტია, ჯერ ვიძახებთ hanoi(n-1, 1, 3, 2) - ეს გადაიტანს ზედა დისკებს დამხმარე ბოძზე. შემდეგ ვბეჭდავთ N-იანი დისკის გადატანას 1-დან 3-ში, და ბოლოს ვიძახებთ hanoi(n-1, 2, 1, 3)-ს, რათა დანარჩენი დისკებიც მივაყოლოთ.
