# Problem Statement — 702. ჰანოის კოშკი

> Copied from [AiaSoft.ge #702](https://aiasoft.ge/problem/702)

**Time limit:** 1.0s &nbsp;|&nbsp; **Memory limit:** 256 MB

## Task

თავსატეხი "ჰანოის კოშკი" შედგება სამი ბოძისაგან, რომლებიც გადანომრილია - 1, 2, 3. 1-ლ ბოძზე ჩამოცმულია N განსხვავებული დიამეტრის მქონდე დისკები, რომლებიც დალაგებულია დიამეტრის კლების მიხედვით (ქვემოდან ზემოთ). ერთ სვლაში შესაძლებელია დისკის აღება რომელიმე ბოძიდან და სხვა ბოძზე გადატანა შემდეგი პირობების დაცვით:
	● დისკის აღება შეილება მხოლოდ იმ შემთხვევაში თუკი ის ბოძზე ზემოდან პირველია.
	● ნებისმიერ ბოძზე დისკები უნდა იყოს დალაგებული დიამეტრის კლებადობის მიხედვით (ქვემოდან ზემოთ).

`~https://storage.googleapis.com/problems_api_photos/images/CXix0bVXdAkATJd9A8Al.png`

დაწერეთ პროგრამა, რომელიც მოცემული N-ისთვის დაბეჭდავს ინსტრუქციას - თუ როგორ უნდა გადავიტანოთ ყველა დისკი პირველი ბოძიდან მესამეზე, ზემოთ აღწერილი ყველა წესის დაცვით და მინიმალური სვლების რაოდენობით.

* დისკები გადანომრილია 1-დან N-ის ჩათვლით, ზემოდან ქვემოთ.

## Input

ერთადერთ ხაზზე მოცემულია ერთი ნატურალური რიცხვი N (1<=N<=10) - ბოძზე დისკების რაოდენობა.

## Output

გამომავალი მონაცემების ყოველი i-ური ხაზი აღნიშნავს i სვლაზე დისკის გადაადგილების ინსტრუქციას და უნდა შეიცავდეს სამ მთელ რიცხვს:
a b c, სადაც a - ეს არის დისკის ნომერი, რომელსაც გადავაადგილებთ, b - არის ბოძის ნომერი, რომლიდანაც ვიღებთ a დისკს, ხოლო c -  არის ბოძის ნომერი, რომელზეც გადაგვაქვს a დისკი.
