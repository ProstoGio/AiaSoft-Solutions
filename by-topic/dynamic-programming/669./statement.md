# Problem Statement — 669. სანდრო და კამათელი

> Copied from [AiaSoft.ge #669](https://aiasoft.ge/problem/669)

**Time limit:** 1.0s &nbsp;|&nbsp; **Memory limit:** 256 MB

## Task

ბაბუამ სანდროს კამათელი აჩუქა. კამათელს როგორც ვიცით 6 წახნაგი აქვს და მათზე 1-დან 6-ის ჩათვლით რიცხვებია დაწერილი. 

პატარა სანდროს ძალიან მოეწონა კამათლით თამაში. ამჯერად მას აინტერესებს, რამდენი განსხვავებული ვარიანტი არსებობს, რომ კამათლის რამდენჯერმე გაგორებით ამოსული ციფრების ჯამი გამოვა N.

## Input

მოცემულია ერთი მთელი რიცხვი - N.
1<=N<=10⁶

## Output

გამობეჭდეთ ერთი მთელი რიცხვი: რამდენი განსხვავებული ვარიანტი არსებობს N-ის მისაღებად. პასუხი გამოიტანეთ 10⁹+7-ზე დანაშთული სახით.
