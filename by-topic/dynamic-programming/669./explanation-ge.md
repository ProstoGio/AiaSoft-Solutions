# განმარტება — 669. სანდრო და კამათელი

## მიდგომა

ეს არის ტიპური DP ამოცანა, სადაც თითოეული ნაბიჯი წინა ექვსზეა დამოკიდებული. იმისთვის, რომ მივიღოთ ჯამი N, შეგვიძლია მოვიდეთ ნებისმიერი პოზიციიდან i-6-დან i-1-მდე და გავაგოროთ შესაბამისი ციფრი, რომ ზუსტად i-ში აღმოვჩნდეთ. გამოვიყენე ვექტორი, სადაც ვინახავთ ყველა შესაძლო კომბინაციას კონკრეტული ჯამის მისაღებად. რადგან პასუხი 10^9+7-ზე დანაშთული გვინდა, მიმატებისას მუდმივად ვსვამთ მოდულს.

## სირთულე

| | |
|-|--|
| დრო | O(N) |
| მეხსიერება | O(N) |

## მთავარი დაკვირვებები

- რეკურენტული ფორმულაა dp[i] = dp[i-1] + ... + dp[i-6].
- dp[0] = 1-ით დაწყება აუცილებელია, რადგან ეს არის ჩვენი საწყისი მდგომარეობა.
- წინსწრებით განახლება (forward DP) კოდს უფრო გამარტივებულს ხდის.

## ხშირი შეცდომები

- მოდულის ოპერაციის დავიწყება, რაც overflow-ს გამოიწვევს.
- მასივის საზღვრების დარღვევა, როცა i < 6-ია.
- dp[0]-ის არასწორად ინიციალიზება.

## ნაბიჯ-ნაბიჯ ახსნა

თავიდანვე ვქმნით 1,000,001 ზომის მასივს. dp[0]-ს ვაყენებთ 1-ზე. ციკლში 0-დან N-1-მდე, თითოეული მნიშვნელობა ვუმატებთ შემდეგ 6 პოზიციას. ბოლოს dp[N]-ში გვექნება ჩვენი პასუხი.
