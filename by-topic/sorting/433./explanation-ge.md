# განმარტება — 433. უცნაური დოღი

## მიდგომა

ამოცანის არსი იმაშია, რომ ვიპოვოთ სიჩქარით მეორე ცხენი. ამისთვის წყვილებისგან (pair) შემდგარ ვექტორს ვიყენებ, სადაც თითოეულ სიჩქარეს მისი ორიგინალი ნომერი მივაბი. როგორც კი მონაცემებს დავალაგებ ზრდადობით, ყველაზე სწრაფი ბოლოში აღმოჩნდება, შესაბამისად მეორე ადგილზე მყოფი ცხენი ზუსტად ბოლოს წინა ინდექსზე იქნება.

## სირთულე

| | |
|-|--|
| დრო | O(N log N) |
| მეხსიერება | O(N) |

## მთავარი დაკვირვებები

- pair-ის გამოყენება ყველაზე მარტივი გზაა ცხენის ინდექსის შესანარჩუნებლად.
- სორტირება ავტომატურად აწყობს ცხენებს სიჩქარის მიხედვით.

## ხშირი შეცდომები

- თუ უბრალოდ მასივს დაალაგებ, ცხენების ორიგინალი ნომრები დაიკარგება.
- ინდექსების არევა, როცა n-2-ის მაგივრად სხვა პოზიციას ეძებ.

## ნაბიჯ-ნაბიჯ ახსნა

შემოგვაქვს N, ვქმნით pair-ების ვექტორს, შეგვაქვს სიჩქარეები და ინდექსები (i+1), ვატარებთ sort-ს და ვბეჭდავთ ბოლოს წინა ცხენის ინდექსს.
