# Problem Statement — 433. უცნაური დოღი

> Copied from [AiaSoft.ge #433](https://aiasoft.ge/problem/433)

**Time limit:** 1.0s &nbsp;|&nbsp; **Memory limit:** 256 MB

## Task

ანზორიკოს ძალიან უყვარს დოღის ყურება და ამავდროულად, დოღის ცხენებზე ფსონის დადება. მოგეხსენებათ, რომ დოღი ჯიშიანი საჯდომი ცხენების გამოცდაა. დოღში გამარჯვებულად ითვლება ის ცხენი , რომელიც ყველაზე სწრაფად გაივლის მოცემულ მონაკვეთს და პირველი გადაკვეთს "ფინიშის ხაზს". 

	ერთხელ ანზორიკომ გადაწყვიტა, რომ უცნაურ დოღშიც გამოსცადოს ბედი. უცნაური დოღის გამარჯვებულია ცხენი, რომელიც `bრიგით მეორე` გადაკვეთს "ფინიშის ხაზს". უცნაურ დოღში სულ N ცხენი იღებს მონაწილეობას. ცხენები 1-დან N-ის ჩათვლის არიან გადანომრილები. საბედნიეროდ, ანზორიკომ თითოეული ცხენის სიჩქარე იცის. დაეხმარეთ ანზორიკოს დაადგინოს თუ რომელი ნომერი ცხენი იქნება უცნაური დოღის გამარჯვებული.

## Input

პირველ სტრიქონზე შემოდის N- უცნაურ დოღში ცხენების რაოდენობა. 2<=N<=100

მეორე სტრიქონზე შემოდის N რაოდენობის რიცხვი - a1, a2...ai...aN, სადაც ai არის i ნომერი ცხენის სიჩქარე. 1<=ai<=5*10⁴

## Output

გამოიტანეთ ერთადერთი რიცხვი - უცნაური დოღის გამარჯვებული ცხენის ნომერი.
