# განმარტება — 726. მრავალჯერადი ფაქტორიალი

## მიდგომა

ამოცანის არსი იმაშია, რომ ფაქტორიალები ძალიან სწრაფად იზრდება. როგორც კი რიცხვი 5-ს აღწევს, ის უკვე შეიცავს 2-ს და 5-ს, რაც იმას ნიშნავს, რომ ბოლო ციფრი აუცილებლად 0 იქნება. მე დავაპარსე სტრიქონი, რომ გამომეყო n და '!' სიმბოლოების რაოდენობა. პატარა რიცხვებისთვის ხელით გავთვალე შედეგები, დანარჩენისთვის კი ლოგიკა მარტივია: თუ გამოთვლის პროცესში რიცხვი 5-ს გადააჭარბებს, შედეგი 0-ით მთავრდება.

## სირთულე

| | |
|-|--|
| დრო | O(N + K) |
| მეხსიერება | O(N) |

## მთავარი დაკვირვებები

- n! როცა n >= 5, ბოლოვდება 0-ით.
- ((n!)!)! იმდენად სწრაფად იზრდება, რომ n >= 3 და k > 1 შემთხვევაში შედეგი ყოველთვის 0-ია.
- 0! და 1! გამონაკლისებია და უდრის 1-ს.

## ხშირი შეცდომები

- ფაქტორიალის პირდაპირი გამოთვლა, რაც აუცილებლად გამოიწვევს overflow-ს.
- 0-ის ან 1-ის სპეციალური შემთხვევების გამოტოვება.

## ნაბიჯ-ნაბიჯ ახსნა

თავიდან სტრიქონს ვყოფ ორ ნაწილად: რიცხვად და ძახილის ნიშნების რაოდენობად. შემდეგ ვამოწმებ n-ის მნიშვნელობებს. თუ n არის 0 ან 1, ვბეჭდავ 1-ს. თუ n=2, ვბეჭდავ 2-ს. 3-ისა და 4-ისთვის ვუყურებ ძახილის ნიშნების რაოდენობას: თუ კენტია (ანუ 1), შედეგი კონკრეტული რიცხვია, ხოლო თუ 1-ზე მეტია, მაშინვე 0-ს ვბეჭდავ, რადგან ფაქტორიალი უკვე 5-ს გადაცილებულია.
