# Problem Statement — 772. სიმბოლოთა სიხშირე

> Copied from [AiaSoft.ge #772](https://aiasoft.ge/problem/772)

**Time limit:** 1.0s &nbsp;|&nbsp; **Memory limit:** 256 MB

## Task

მოცემულია S სტრიქონი, რომელიც შეიცავს ლათინური ანბანის დაბალი რეგისტრის სიმბოლოებს. იპოვეთ თითოეული სიმბოლოს სიხშირე. სიმბოლოს სიხშირე ეწოდება მოცემულ S სტრიქონში ამ სიმბოლოს რაოდენობას.

## Input

პირველ ხაზზე მოცემულია S.
1<=|S|<=10⁵

## Output

ერთ ხაზზე გამობეჭდეთ თითოეული სიმბოლოს სიხშირე, ლათინური ანბანის სიმბოლოთა რიგითობის მიხედვით.
