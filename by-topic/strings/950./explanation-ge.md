# განმარტება — 950. ახალი სიტყვები

## მიდგომა

ამოცანის არსი იმაშია, რომ ვიპოვოთ A სტრიქონის ყველაზე გრძელი სუფიქსი, რომელიც ამავდროულად B-ს პრეფიქსია. მე ვამოწმებ B-ს ყველა პრეფიქსს და ვადარებ A-ს ბოლოს. როგორც კი ვიპოვი მაქსიმალურ დამთხვევას (k), უბრალოდ A-ს მივაწერ B-ს იმ ნაწილს, რომელიც კ-ს შემდეგ მოდის. მარტივი და ეფექტურია ამ ზომის შეზღუდვისთვის.

## სირთულე

| | |
|-|--|
| დრო | O(N * min(N, M)) |
| მეხსიერება | O(N + M) |

## მთავარი დაკვირვებები

- გადაფარვის მაქსიმალური სიგრძე ვერ იქნება უფრო დიდი, ვიდრე უმოკლესი სტრიქონის სიგრძე.
- სტრიქონების შედარება მარტივი ციკლით საკმარისია, რადგან 5000-მდე სიგრძის სტრიქონებისთვის O(N^2) დროში ჩაეტევა.

## ხშირი შეცდომები

- კოდში დამთხვევის არარსებობის შემთხვევის (k=0) გამოტოვება.
- სტრიქონების შეერთებისას ინდექსაციაში შეცდომის დაშვება, რამაც შეიძლება ზედმეტი ან ნაკლები სიმბოლოები დაგვიბრუნოს.

## ნაბიჯ-ნაბიჯ ახსნა

ვკითხულობ ორ სიტყვას. ვიწყებ B-ს პრეფიქსების შემოწმებას, ვამოწმებ ემთხვევა თუ არა A-ს დაბოლოებას. ვინახავ ყველაზე გრძელ დამთხვევას k-ში და ბოლოს A-ს ვუერთებ B[k:]-ს.
