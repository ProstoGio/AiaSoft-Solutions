# განმარტება — 244. ჩეთბოტი

## მიდგომა

ამოცანა მარტივია: უბრალოდ უნდა დავითვალოთ რამდენი წინადადება მთავრდება '?' ნიშნით. რადგან დიალოგის ხაზები შეიცავს ჰარებს (spaces), ჩვეულებრივი cin >> s არ გამოგვადგება, ამიტომ getline-ს ვიყენებ. თითოეული სტრიქონის ბოლო სიმბოლოს ვამოწმებ და თუ '?' შეგვხვდა, კითხვების მთვლელს ვზრდი, სხვა შემთხვევაში - პასუხებისას.

## სირთულე

| | |
|-|--|
| დრო | O(N * L) |
| მეხსიერება | O(L) |

## მთავარი დაკვირვებები

- cin >> n-ის შემდეგ ბუფერში რჩება 'enter'-ის სიმბოლო, ამიტომ n++-ს ვიყენებ, რომ პირველი getline-მა ცარიელი სტრიქონი არ წაიკითხოს.
- სტრიქონის ბოლო სიმბოლოზე წვდომა q[sz-1]-ით ყველაზე სწრაფი გზაა.

## ხშირი შეცდომები

- cin-ის შემდეგ ბუფერის გასუფთავების დავიწყება.
- getline-ის ნაცვლად cin >>-ის გამოყენება, რაც წინადადებებს მხოლოდ სიტყვებად დაშლის.

## ნაბიჯ-ნაბიჯ ახსნა

შემოგვაქვს n, მერე n+1-ჯერ ვუშვებთ ციკლს, რომ getline-მა სწორად იმუშაოს. ყოველი შეტყობინების ბოლო სიმბოლოს ვამოწმებთ. თუ q.back() არის '?', ესე იგი კითხვაა. ვბეჭდავთ ჯერ კითხვების რაოდენობას, შემდეგ პასუხებისას.
