# Problem Statement — 228. წაშლილი მატრიცა

> Copied from [AiaSoft.ge #228](https://aiasoft.ge/problem/228)

**Time limit:** 1.0s &nbsp;|&nbsp; **Memory limit:** 256 MB

## Task

An * n მატრიცა მხოლოდ ციფრებისაგან შედგება. ამ მატრიცისაგან შექმნეს ერთი სტრიქონი შემდეგი წესით: ჯერ ამოწერეს მატრიცის პირველი სტრიქონის ელემენტები, შემდეგ მას მიუწერეს მეორე სტრიქონის ელემენტები და ა. შ. ჰარების გარეშე.

მოცემული გვაქვს მხოლოდ მატრიცისგან მიღებული სტრიქონი. დაწერეთ პროგრამა, რომელიც იპოვის საწყისი მატრიცის მარცხენა მთავარი დიაგონალის ელემენტების ჯამს.

## Input

პირველ სტრიქონზე ჩაწერილია მატრიცისგან მიღებული ციფრების მიმდევრობა ჰარების გარეშე. მიმდევრობის სიგრძე არ აღემატება 10000-ს.

## Output

გამოიტანეთ ერთი ნატურალური რიცხვი, საწყისი მატრიცის მარცხენა მთავარი დიაგონალის ელემენტების ჯამი.
