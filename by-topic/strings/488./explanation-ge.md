# განმარტება — 488. გაყოფადობა 11-ზე

## მიდგომა

რადგან რიცხვი 10^1000-მდე შეიძლება იყოს, int ან long long ვერ შეინახავს, ამიტომ სთრინგად წაკითხვა ყველაზე მარტივი გზაა. 11-ზე გაყოფადობის წესი მარტივია: კენტ და ლუწ პოზიციებზე მდგომი ციფრების ჯამების სხვაობა უნდა იყოფოდეს 11-ზე. კოდში უბრალოდ ციკლით გავიარე სტრიქონი, ინდექსების მიხედვით დავაჯამეთ ციფრები და ბოლოს შევამოწმე ნაშთი.

## სირთულე

| | |
|-|--|
| დრო | O(N) |
| მეხსიერება | O(N) |

## მთავარი დაკვირვებები

- სტრიქონით მუშაობა გვაძლევს საშუალება, ძალიან დიდი რიცხვები მარტივად დავამუშაოთ.
- ალგორითმი პირდაპირ მათემატიკურ წესს მიჰყვება და დამატებითი მეხსიერება თითქმის არ სჭირდება.

## ხშირი შეცდომები

- რიცხვის მთელ ტიპად (integer) შენახვა, რაც 10^1000-ის შემთხვევაში აუცილებლად გამოიწვევს Overflow-ს.
- ინდექსების არევა (0-დან იწყება დათვლა C++-ში, რაც უნდა გავითვალისწინოთ).

## ნაბიჯ-ნაბიჯ ახსნა

შემოყვანილი სტრიქონის თითოეულ სიმბოლოს ვაკონვერტირებ ციფრად (n[i] - '0')-ით. თუ ინდექსი ლუწია, ვამატებ odd_sum-ს, თუ კენტია - even_sum-ს. ბოლოს, თუ (odd_sum - even_sum) იყოფა 11-ზე, ვბეჭდავ YES-ს, სხვა შემთხვევაში NO-ს.
