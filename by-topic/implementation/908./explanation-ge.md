# განმარტება — 908. სუნთქვა 2

## მიდგომა

ამოცანა საკმაოდ მარტივია, რადგან ზუკას სუნთქვის ციკლი ყოველ 4 ნაბიჯში მეორდება. 1-2 ჩასუნთქვაა, 3-4 ამოსუნთქვა. რეალურად, თუ რიცხვს გავყოფთ 4-ზე, ნაშთით მარტივად გავიგებთ რომელ ფაზაში ვართ. ჩემს კოდში ოდნავ სხვა მიდგომა გამოვიყენე n/2-ით და n%2-ით, რაც საბოლოოდ იმავე შედეგამდე მიდის.

## სირთულე

| | |
|-|--|
| დრო | O(1) |
| მეხსიერება | O(1) |

## მთავარი დაკვირვებები

- ციკლი მეორდება ყოველ 4 რიცხვში.
- ნაშთით (mod 4) მუშაობა ყველაზე მოკლე გზაა.

## ხშირი შეცდომები

- 4-ის შემთხვევის გამოტოვება, რადგან ის 'ამოსუნთქვაა' და ნაშთი 0-ს გვაძლევს.
- პირობის ზედმეტად დართულება, როცა შეიძლება უბრალოდ if (n % 4 == 1 || n % 4 == 2) გამოვიყენოთ.

## ნაბიჯ-ნაბიჯ ახსნა

ჯერ ვითვლი k = n/2-ს და r = n%2-ს. ეს დამეხმარა დამედგინა, წყვილის რომელ ნახევარში ვარ. შემდეგ if-else პირობებით ვამოწმებ k-ს ლუწ-კენტობას და r-ს, რათა ზუსტად გავიგო 'Breathe in' უნდა დაიბეჭდოს თუ 'Breathe out'.
