# Problem Statement — 693. ასაკი თვეებში

> Copied from [AiaSoft.ge #693](https://aiasoft.ge/problem/693)

**Time limit:** 1.0s &nbsp;|&nbsp; **Memory limit:** 256 MB

## Task

წარმოვიდგინოთ, რომ 2022 წლის პირველი მარტია. თუ თაკო დაიბადა x წელს, მე-y თვის პირველ რიცხვში, მაშინ რამდენი თვისაა თაკო ახლა? (ანუ რამდენი სრულყოფილი თვე გავიდა თაკოს დაბადების დღიდან დღემდე).

## Input

ერთ ხაზზე მოცემულია ორი მთელი რიცხვი: x (0 <= x <= 2022) და y (1 <= y <= 12). 
გარანტირებულია, რომ თაკოს დაბადების თარიღი არ აღემატება ახლანდელ თარიღს (ანუ 2022 წლის პირველ მარტს).

## Output

გამოიტანეთ ერთი მთელი რიცხვი: რამდენი თვისაა თაკო 2022 წლის პირველ მარტს.
