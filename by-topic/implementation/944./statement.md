# Problem Statement — 944. გაეროს შიფრი

> Copied from [AiaSoft.ge #944](https://aiasoft.ge/problem/944)

**Time limit:** 1.0s &nbsp;|&nbsp; **Memory limit:** 256 MB

## Task

გაერთიანებული ერების ორგანიზაციის საინფორმაციო ცენტრი, უსაფრთხოების მიზნით, ყველა შემოსულ დიპლომატიურ წერილს სპეციალური დინამიური შიფრით იღებს. ყოველი ქვეყნის ოფიციალური სახელწოდება, რომელიც მხოლოდ ინგლისური ანბანის დიდი ასოებისგან შედგება, იშიფრება შემდეგი წესით:
	● პროგრამა შემთხვევითობის პრინციპით ირჩევს საიდუმლო ციფრს - k;
	● ქვეყნის სახელის თითოეული ასო ანბანში წანაცვლდება წინ (მარჯვნივ) გარკვეული ბიჯით. i-ური ასოსთვის (ათვლას 1-დან ვიწყებთ) ეს ბიჯი უდრის k×i-ს;
	● მიღებული დაშიფრული სტრინგის ბოლოში (ბოლო ასოს შემდეგ) იწერება თავად ეს საიდუმლო ციფრი k.

მოცემული დაშიფრული სტრინგისთვის, თქვენი დავალებაა აღადგინოთ ქვეყნის საწყისი სახელი.

## Input

ერთადერთ სტრიქონზე მოცემულია ქვეყნის დაშიფრული სახელი S. გარანტირებულია, რომ სტრინგის ბოლო სიმბოლო ყოველთვის არის ციფრი, ხოლო დანარჩენი სიმბოლოები ინგლისური ანბანის დიდი ასოებია.
1≤k≤9
2≤|S|≤10⁵

## Output

გამოიტანეთ ერთი სტრინგი - ქვეყნის გაშიფრული სახელი.
