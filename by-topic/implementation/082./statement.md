# Problem Statement — 082. ისევ ფრჩხილები

> Copied from [AiaSoft.ge #82](https://aiasoft.ge/problem/82)

**Time limit:** 1.0s &nbsp;|&nbsp; **Memory limit:** 256 MB

## Task

მეორეკლასელებმა ისევ მოიტანეს ფრჩხილებიანი გამოსახულება, მაგრამ ამჯერად გამოსახულება შეიცავს როგორც მრგვალ, ასევე ფიგურულ და კვადრატულ ფრჩხილებს. ყველა ზედმეტი სიმბოლო ამოჭრილია, სტრიქონში მხოლოდ ფრჩხილებია. ბავშვებს აინტერესებთ, სწორადაა თუ არა ჩაწერილი მათი გამოსახულება.

ცნობილია, რომ:
1. ()  გამოსახულება სწორია;
2. {} გამოსახულება სწორია;
3. [ ] გამოსახულება სწორია;
4. ორი სწორი გამოსახულების ერთმანეთზე გადაბმით (ნებისმიერი თანმიმდევრობით) მიიღება სწორი გამოსახულება;
5. თუ ნებისმიერ სწორ გამოსახულებას ჩავსვამთ მრგვალ, ფიგურულ ან კვადრატულ ფრჩხილებში, მიიღება სწორი გამოსახულება.

შეგახსენებთ, რომ მეორეკლასელების გამოსახულება შეიცავს მხოლოდ ფრჩხილებს.

## Input

ერთ სტრიქონში შემოდის ფრჩხილების შემცველი გამოსახულება, მისი სიგრძე არ აღემატება 200 სიმბოლოს. გამოსახულება შეიცავს მრგვალ (), ფიგურულ {} და კვადრატულ [ ] ფრჩხილებს.

## Output

გამოიტანეთ სიტყვა YES, თუ გამოსახულება სწორადაა ჩაწერილი, NO - წინააღმდეგ შემთხვევაში.
