# განმარტება — 082. ისევ ფრჩხილები

## მიდგომა

ეს კლასიკური ამოცანაა, სადაც stack-ი უნდა გამოვიყენოთ ფრჩხილების სწორი თანმიმდევრობის შესამოწმებლად. როგორც კი გამხსნელ ფრჩხილს ვხედავ, stack-ში ვაგდებ, ხოლო დამხურავის შემთხვევაში ვამოწმებ, stack-ის თავში იგივე ტიპის ფრჩხილია თუ არა. თუ ყველაფერი ემთხვევა, ვაკეთებ pop-ს. ბოლოს ვამოწმებ, stack-ი ცარიელია თუ არა და ნაშთები ხომ არ დარჩა, რადგან დაუხურავი ფრჩხილები დაუშვებელია.

## სირთულე

| | |
|-|--|
| დრო | O(n) |
| მეხსიერება | O(n) |

## მთავარი დაკვირვებები

- stack-ი იდეალურია ფრჩხილების LIFO წესის დასაცავად.
- ყოველი დამხურავი ფრჩხილი აუცილებლად უნდა ემთხვეოდეს stack-ის ბოლო ელემენტს.
- ბოლოში თვლა (counter-ებით) დაზღვევაა, რომ ყველა ფრჩხილი დახურულია.

## ხშირი შეცდომები

- stack-ის ცარიელობის შემოწმების დავიწყება pop-ის წინ.
- არასწორი ფრჩხილების ტიპების შედარება.
- სტრიქონის დასაწყისშივე დამხურავი ფრჩხილის არსებობის გაუთვალისწინებლობა.

## ნაბიჯ-ნაბიჯ ახსნა

სტრიქონს ვკითხულობ და ციკლით მივყვები თითოეულ სიმბოლოს. თუ გამხსნელი ფრჩხილია, stack-ში ვუმატებ. თუ დამხურავია, ვამოწმებ stack-ის თავზე რა დევს. თუ stack-ი ცარიელია ან ტიპები არ ემთხვევა, მაშინვე ვბეჭდავ 'NO'-ს და ვწყვეტ მუშაობას. ბოლოს დამატებით ვამოწმებ თითოეული ტიპის ფრჩხილის რაოდენობას, და თუ ყველაფერი ნულია, მაშინ პასუხია 'YES'.
