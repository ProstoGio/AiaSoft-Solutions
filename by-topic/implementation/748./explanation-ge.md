# განმარტება — 748. ბედნიერი რიცხვები

## მიდგომა

რადგანაც A და B არის 100,000-დან 999,999-მდე, brute force სრულიად საკმარისია. დავწერე ფუნქცია check, რომელიც ციფრებს ყოფს modulo და გაყოფის ოპერაციებით. ვამოწმებ პირველი სამი ციფრის ჯამს და ბოლო სამისას. მთავარ ციკლში უბრალოდ ვუვლი A-დან B-მდე ყველა რიცხვს და თუ ფუნქცია true-ს დამიბრუნებს, მთვლელს ვზრდი.

## სირთულე

| | |
|-|--|
| დრო | O(N) |
| მეხსიერება | O(1) |

## მთავარი დაკვირვებები

- ამ ტიპის ამოცანაში მათემატიკური ოპერაციები ბევრად სწრაფია ვიდრე რიცხვის სტრინგად გადაყვანა.
- შეზღუდვა 10^6-ია, რაც C++-ისთვის მიზერული დატვირთვაა 3 წამში.

## ხშირი შეცდომები

- ინდექსების არევა ციფრების გამოყოფისას.
- არასწორი საზღვრები ციკლში (მაგალითად, a < b, როცა a <= b უნდა იყოს).

## ნაბიჯ-ნაბიჯ ახსნა

კოდი იღებს A და B მნიშვნელობებს, შემდეგ while ციკლით გადის ყოველ რიცხვს. check ფუნქციაში რიცხვს ვშლი 6 ცალკეულ ციფრად, ვამატებ მათ შესაბამისად და ვადარებ ერთმანეთს. ბოლოს უბრალოდ ვბეჭდავთ მიღებულ პასუხს.
