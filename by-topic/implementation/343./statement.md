# Problem Statement — 343. საბავშვო მოედანი 3

> Copied from [AiaSoft.ge #343](https://aiasoft.ge/problem/343)

**Time limit:** 1.0s &nbsp;|&nbsp; **Memory limit:** 256 MB

## Task

საბავშვო მოედნის გარშემო N რაოდენობის სკამია განლაგებული და, რა თქმა უნდა, გადანომრილია 1-დან N-ის ჩათვლით.
`bსამმა` მეგობარმა, გიგიკომ და გუგიკომ და გივიკომ სხვადასხვა დროს შეიძინეს ბილეთები საბავშვო კონცერტზე დასასწრებად. თითოეულ ბილეთს სკამის ნომერი აწერია.
მეგობრებს ძალიან უნდათ ერთმანეთის გვერდით ჯდომა.
დაწერეთ პროგრამა, რომელიც დაბეჭდავს სიტყვას YES, თუ გიგიკო, გუგიკო და გივიკო ერთმანეთის გვერდით აღმოჩნდებიან, და სიტყვას NO - წინააღმდეგ შემთხვევაში.

## Input

პირველ სტრიქონზე შემოდის ერთი მთელი დადებითი რიცხვი N, 3<=N<=100 - მოედნის გარშემო სკამების რაოდენობა.
მეორე სტრიქონზე შემოდის ერთმანეთისაგან ერთი ჰარით დაშორებული სამი მთელი დადებითი რიცხვი - გიგიკოს, გუგიკოს და გივიკოს სკამების ნომრები.

## Output

გამოიტანეთ ერთი სიტყვა YES ან NO. შესაბამისად, აღმოჩნდნენ თუ არა მეგობრები ერთმანეთის გვერდით.
