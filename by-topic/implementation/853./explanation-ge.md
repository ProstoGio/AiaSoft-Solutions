# განმარტება — 853. გამოკლება ლაშას წესით

## მიდგომა

ამ ამოცანის არსი იმაშია, რომ სტრიქონიდან გამოვყოთ ორი რიცხვი, რომლებიც '-' ნიშნითაა გაყოფილი. უბრალოდ ვამოწმებ თითოეულ სიმბოლოს, თუ '-' შევხვდი, მაშინ უკვე მეორე რიცხვის აწყობას ვიწყებ. ბოლოს, თუ პირველი რიცხვი მეორეზე ნაკლებია, ნულს ვბეჭდავ, სხვა შემთხვევაში კი ჩვეულებრივ სხვაობას.

## სირთულე

| | |
|-|--|
| დრო | O(N * L) |
| მეხსიერება | O(L) |

## მთავარი დაკვირვებები

- ინფუთის წაკითხვა while(cin >> s)-ით ყველაზე მოსახერხებელია, რადგან არ ვიცით რამდენი მაგალითი იქნება.
- ლაშას წესი პრაქტიკულად max(0, x - y) ფუნქციაა.

## ხშირი შეცდომები

- რიცხვების კონვერტაციისას სტრუქტურის არასწორად გათვლა.
- უარყოფითი შედეგის პირდაპირ დაბეჭდვა, პირობის შემოწმების გარეშე.

## ნაბიჯ-ნაბიჯ ახსნა

თავიდან სტრიქონს ვყოფ ორ ნაწილად, მერე თითოეულს ვცვლი int-ად. ლოგიკა ძალიან მარტივია: თუ (n1 - n2 < 0), მაშინ ვბეჭდავთ 0-ს, სხვა შემთხვევაში (n1 - n2)-ს. ეგ არის მთელი ამბავი.
