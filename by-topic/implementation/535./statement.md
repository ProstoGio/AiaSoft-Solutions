# Problem Statement — 535. ყოვლისშემძლე რიცხვი

> Copied from [AiaSoft.ge #535](https://aiasoft.ge/problem/535)

**Time limit:** 1.0s &nbsp;|&nbsp; **Memory limit:** 256 MB

## Task

მოცემულია N ნატურალური რიცხვი. თქვენი დავალებაა ამ რიცხვებიდან ამოარჩიოთ `bყოვლისშემძლე` რიცხვი.
ყოვლისშემძლე ეწოდება ისეთ რიცხვს, რომელზეც უნაშთოდ იყოფა ყველა მოცემული რიცხვი.

## Input

პირველ ხაზზე მოცემულია ერთი ნატურალური რიცხვი: N. (1 <= N <= 10⁵)
მომდევნო ხაზზე მოცემულია N რაოდენობის ნატურალური რიცხვი: a1, a2, ..., an, (1 <= ai <= 10⁵)

## Output

თუ მოცემულ რიცხვებში არსებობს ყოვლისშემძლე რიცხვი, მაშინ გამობეჭდეთ იგი. წინააღმდეგ შემთხვევაში გამობეჭდეთ `b-1`.
