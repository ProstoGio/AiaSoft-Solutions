# განმარტება — 535. ყოვლისშემძლე რიცხვი

## მიდგომა

თუ რიცხვი ყოვლისშემძლეა, ის აუცილებლად უნდა იყოფოდეს სიაში არსებულ ყველა რიცხვზე. ეს ნიშნავს, რომ ის თავად უნდა იყოს ყველაზე პატარა რიცხვი, ან მასზე პატარა. თუმცა, რადგან ყოვლისშემძლე რიცხვი თავად არის მოცემული მასივის წევრი, ერთადერთი კანდიდატი არის მასივის მინიმალური ელემენტი. ამიტომ, ვიპოვი მინიმალურს და შევამოწმებ, იყოფა თუ არა მასზე დანარჩენი რიცხვები.

## სირთულე

| | |
|-|--|
| დრო | O(N log N) |
| მეხსიერება | O(N) |

## მთავარი დაკვირვებები

- ყოვლისშემძლე რიცხვი მხოლოდ მინიმალური ელემენტი შეიძლება იყოს.
- საკმარისია მხოლოდ მინიმალურის შემოწმება დანარჩენებთან.
- set-ის გამოყენება გვეხმარება დუბლიკატების მარტივად თავიდან არიდებაში.

## ხშირი შეცდომები

- ისეთი შემთხვევების გამოტოვება, როცა პასუხი -1-ია.
- GCD-ის ზედმეტად გამოთვლა მაშინ, როცა პირდაპირი გაყოფა საკმარისია.

## ნაბიჯ-ნაბიჯ ახსნა

თავდაპირველად, რიცხვებს ვინახავ vector-ში და ამავდროულად ვპოულობ მინიმალურს. პარალელურად ვყრი set-ში, რომ უნიკალური მნიშვნელობები მქონდეს. შემდეგ set-ზე ვტრიალებ და ვამოწმებ, თუ რომელიმე რიცხვი მინიმალურზე უნაშთოდ არ იყოფა, მაშინვე ვბეჭდავ -1-ს. თუ ციკლი უპრობლემოდ მორჩა, ვბეჭდავ ნაპოვნ მინიმალურ რიცხვს.
