# განმარტება — 772. სიმბოლოთა სიხშირე

## მიდგომა

ეს არის კლასიკური counting problem, სადაც სტრიქონში თითოეული სიმბოლოს რაოდენობა უნდა დავითვალოთ. რადგან მხოლოდ ლათინური პატარა ასოები გვაქვს, გამოვიყენე 150-იანი მასივი, სადაც ასოების ASCII კოდები ინდექსებად გამოდგება. პირველი ციკლით სტრიქონს გადავუვლი და 'freq' მასივში შესაბამის უჯრას ვზრდი, შემდეგ კი 97-დან 122-მდე გამოგვაქვს შედეგები.

## სირთულე

| | |
|-|--|
| დრო | O(N) |
| მეხსიერება | O(1) |

## მთავარი დაკვირვებები

- ASCII ცხრილში 'a'-დან 'z'-მდე სიმბოლოები მიყოლებითაა, რაც ინდექსირებას ამარტივებს.
- მეხსიერება მუდმივია (O(1)), რადგან ასოების რაოდენობა შეზღუდულია.

## ხშირი შეცდომები

- map-ის გამოყენება, რაც ამ კონკრეტულ შემთხვევაში უბრალოდ ზედმეტი რესურსის ხარჯვაა.
- 97-დან 122-მდე ინტერვალის არევა ან არასწორი დიაპაზონის დაბეჭდვა.

## ნაბიჯ-ნაბიჯ ახსნა

შემოვიტანე სტრიქონი 's'. 'for' ციკლით თითოეულ სიმბოლოს მივწვდი და 'freq[s[i]]++'-ით დავითვალე სიხშირე. ბოლოს, კიდევ ერთი ციკლით 'a'-დან 'z'-მდე გამოვუტანე მომხმარებელს დათვლილი მნიშვნელობები.
