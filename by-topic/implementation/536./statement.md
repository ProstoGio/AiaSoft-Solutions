# Problem Statement — 536. გამქრალი სიმბოლო

> Copied from [AiaSoft.ge #536](https://aiasoft.ge/problem/536)

**Time limit:** 1.0s &nbsp;|&nbsp; **Memory limit:** 256 MB

## Task

მოცემულია ლათინური ანბანი პატარა ასოებისაგან შედგენილი სტრიქონი.
დაადგინეთ, ანბანის რომელი პატარა ასოები აკლია მოცემულ სტრიქონს.

## Input

პირველ სტრიქონზე შემოდის ლათინური პატარა ასოებისაგან შედგენილი სტრიქონი.
სტრიქონის სიგრძე არ აღემატება 100 სიმბოლოს.

## Output

ერთ სტრიქონზე გამოიტანეთ ლათინური ანბანის ყველა ის პატარა სიმბოლო, რომელიც არ გვხვდება მოცემულ სტრიქონში.
გამოტანილი სიმბოლოები უნდა იყოს ალფავიტის მიხედვით დალაგებული. 
სიმბოლოები ერთმანეთისაგან გამოყავით თითო ჰარით.
თუ მოცემული სტრიქონს არ აკლია არცერთი სიმბოლო, მაშინ გამოიტანეთ სიტყვა "Complete".
