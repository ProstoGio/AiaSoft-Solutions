# განმარტება — 536. გამქრალი სიმბოლო

## მიდგომა

მოკლედ რომ ვთქვათ, ჯერ დავალაგე სტრიქონი და წავშალე დუბლიკატები, რომ მარტივად შემედარებინა ანბანის სიმბოლოებთან. ამის შემდეგ უბრალო while ციკლით მივყვები 'a'-დან 'z'-მდე და ვამოწმებ, ზის თუ არა ეს სიმბოლო ჩემს დამუშავებულ სტრიქონში. თუ ვერ ვიპოვე, ვამატებ პასუხების ვექტორში და ბოლოს გამოვაჩენ შედეგს.

## სირთულე

| | |
|-|--|
| დრო | O(N log N) |
| მეხსიერება | O(N) |

## მთავარი დაკვირვებები

- sort-ის გამოყენებით სტრიქონის დამუშავება ბევრად მარტივი ხდება.
- ASCII კოდების გამოყენება 'a'-დან 'z'-მდე იდეალურია ამ ტიპის ამოცანისთვის.

## ხშირი შეცდომები

- Complete-ის გამოტანის დავიწყება, თუ ყველა სიმბოლო ადგილზეა.
- ინდექსების არევა სტრიქონის შედარებისას.

## ნაბიჯ-ნაბიჯ ახსნა

შემოსულ სტრიქონს ვალაგებ და `s2`-ში გადამაქვს მხოლოდ უნიკალური სიმბოლოები. შემდეგ `c` ცვლადით, რომელიც 'a'-დან იწყება, მივყვები ანბანს. თუ `s[i]` არ უდრის `c`-ს, ესე იგი `c` აკლია და ვინახავ, სხვა შემთხვევაში ორივე ინდექსს ვზრდი და ვაგრძელებ შედარებას.
