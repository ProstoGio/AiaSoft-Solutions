# Problem Statement — 244. ჩეთბოტი

> Copied from [AiaSoft.ge #244](https://aiasoft.ge/problem/244)

**Time limit:** 1.0s &nbsp;|&nbsp; **Memory limit:** 256 MB

## Task

ჩეთბოტი არის ერთგვარი პროგრამა, რომელიც ავტომატურად პასუხობს კითხვებზე ან სვამს კითხვებს რაიმე ინფორმაციის დასაზუსტებლად.

დიალოგისას გაგზავნილი შეტყობინება შედგება მხოლოდ ლათინური ანბანის ასოებისგან, პუნქტუაციის ზოგიერთი სიმბოლოებისგან ".,?!" ან ჰარებისგან. შეტყობინება არის ორი სახის, კითხვა ან პასუხი. თუ შეტყობინება არის კითხვა იგი სრულდება კითხვის ნიშნით "?". თუ არის პასუხი მაშინ სრულდება კითხვის ნიშნისგან განსხვავებული რაიმე სიმბოლოსგან.

მოცემული გაქვთ ჩეთბოტსა და ერთერთ მომხმარებელს შორის დიალოგი. დაადგინეთ რამდენი კითხვა დაისვა და რამდენი პასუხი გაიცა დიალოგისას.

## Input

პირველ ხაზზე შემოდის ნატურალური რიცხვი n (1<=n<=100), დიალოგში შეტყობინებების რაოდენობა. შემდეგ n ხაზზე შემოდის შეტყობინებები, რომელიც შედგება ლათინური ანბანის სიმბოლოებისგან, პუნქტუაციის ნიშნებისგან (მხოლოდ ".,?!" ) ან ჰარისგან.
გარანტირებულია, რომ სრულ დიალოგში სიმბოლოების რაოდენობა არ აღემატება 20000-ს.

## Output

პირველ ხაზზე გამოიტანეთ ერთი რიცხვი, რამდენი კითხვაც დაისვა დიალოგისას. ხოლო მეორე ხაზზე გამოიტანეთ რამდენი პასუხიც გაიცა.
