# განმარტება — 440. მასივი 1

## მიდგომა

ამოცანა მოითხოვს მასივის შებრუნებას და კენტ ინდექსებზე მდგომი ელემენტების გამოტანას. თავიდან ვიღებ მასივს, მერე კი two-pointer მეთოდით (left და right მაჩვენებლებით) ვუცვლი ელემენტებს ადგილებს, სანამ შუამდე არ მივალ. ბოლოს უბრალოდ ვამოწმებ თითოეულ ინდექსს i%2!=0 პირობით და ვბეჭდავ მხოლოდ იმ ელემენტებს, რომლებიც ამ პირობას აკმაყოფილებს.

## სირთულე

| | |
|-|--|
| დრო | O(N) |
| მეხსიერება | O(N) |

## მთავარი დაკვირვებები

- შებრუნება ყველაზე მარტივად ორპოინტერიანი მეთოდით კეთდება, რაც მეხსიერებას ზოგავს.
- კენტი ინდექსები C++-ში იწყება 1-დან, 3-დან და ა.შ.

## ხშირი შეცდომები

- ინდექსების არევა, როცა 0-საც კენტად თვლიან.
- ციკლის საზღვრების არასწორად განსაზღვრა.

## ნაბიჯ-ნაბიჯ ახსნა

ჯერ ვავსებ ვექტორს, მერე swap-ის საშუალებით ვატრიალებ მასივს, ბოლოს კი `if(i%2!=0)` პირობით გამოვიტან სასურველ ელემენტებს.
