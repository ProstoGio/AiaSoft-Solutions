# Problem Statement — 440. მასივი 1

> Copied from [AiaSoft.ge #440](https://aiasoft.ge/problem/440)

**Time limit:** 1.0s &nbsp;|&nbsp; **Memory limit:** 256 MB

## Task

მოცემულია ერთგანზომილებიანი მასივი. შეატრიალეთ იგი სიმეტრიულად და გამობეჭდეთ კენტ ინდექსებზე მდგომი ელემენტები.

## Input

პირველ სტრიქონზე მოთავსებულია ერთი ნატურალური რიცხვი N - მასივის ელემენტების რაოდენობა. მეორე სტრიქონზე ჩაწერილია N რაოდენობის მთელი რიცხვი a1, a2, ..., an - მასივის ელემენტები.
1<=N<=100
-100<=ak<=100

## Output

ერთ სტრიქონზე გამოიტანეთ ერთმანეთისაგან თითო ჰარით დაშორებული მთელი რიცხვები - შეტრიალებული მასივის კენტ ინდექსებზე მდგომი ელემენტები.
