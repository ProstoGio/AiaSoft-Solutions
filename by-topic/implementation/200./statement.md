# Problem Statement — 200. რიცხვების შედარება

> Copied from [AiaSoft.ge #200](https://aiasoft.ge/problem/200)

**Time limit:** 1.0s &nbsp;|&nbsp; **Memory limit:** 64 MB

## Task

მოცემულია ორი რიცხვი. შეადარეთ ისინი ერთმანეთს.

## Input

ცალ-ცალკე ხაზზე შემოდის რიცხვები a და b  (0 <= a, b <= 10¹⁰⁰)

## Output

თუ a > b გამობეჭდეთ >
თუ a < b გამობეჭდეთ <
თუ a = b გამობეჭდეთ =
