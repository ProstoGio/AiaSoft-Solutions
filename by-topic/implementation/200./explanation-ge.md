# განმარტება — 200. რიცხვების შედარება

## მიდგომა

რადგან რიცხვები 10^100-ს აღწევს, ჩვეულებრივი int ან long long ვერ გაქაჩავს, ამიტომ სტრინგებად წავიკითხე. ჯერ სიგრძეებს ვადარებ, რადგან უფრო გრძელი რიცხვი ავტომატურად დიდია. თუ სიგრძეები ტოლია, მაშინ თითოეულ სიმბოლოს ვამოწმებ მარცხნიდან მარჯვნივ.

## სირთულე

| | |
|-|--|
| დრო | O(N) |
| მეხსიერება | O(N) |

## მთავარი დაკვირვებები

- სტრინგი იდეალურია ისეთი რიცხვებისთვის, რომლებიც int-ში არ ეტევა.
- სიგრძის შედარება არის ოპტიმალური გზა დიდი რიცხვების სწრაფად გასარჩევად.

## ხშირი შეცდომები

- long long-ის გამოყენება, რომელიც 10^100-სთვის საკმარისი არაა.
- სიგრძეების შემოწმების გარეშე უშუალოდ სიმბოლოების შედარება.

## ნაბიჯ-ნაბიჯ ახსნა

შემომყავს 'a' და 'b' სტრინგებად. ჯერ ვამოწმებ რომელი სტრინგია უფრო გრძელი. თუ სიგრძეები ემთხვევა, ვიწყებ ციკლს. პირველივე განსხვავებულ პოზიციაზე ვხვდები რომელია მეტი. თუ ციკლი უპრობლემოდ დასრულდა, ე.ი. რიცხვები ტოლია.
